# Fitness-Wissens-Quiz (DLAMSD01)

iOS-Quiz-App zum Trainieren von Fitness-Wissen (Trainingslehre, Ernährung, Übungsausführung), entwickelt als Projektbericht-Grundlage für den IU-Kurs DLAMSD01 – Apple Mobile Solution Development I.

- SwiftUI + einfaches MVVM, keine Fremd-Frameworks
- Eigenes Design-System ("GreenDarkFitness"), siehe `FitnessQuiz/DesignSystem/`
- Entwicklungsprozess: siehe `docs/journal.md`

## Projekt öffnen

```bash
open FitnessQuiz.xcodeproj
```

Das Xcode-Projekt wird mit [XcodeGen](https://github.com/yonaskolb/XcodeGen) aus `project.yml` erzeugt. Nach Änderungen an `project.yml` neu generieren:

```bash
xcodegen generate
```
